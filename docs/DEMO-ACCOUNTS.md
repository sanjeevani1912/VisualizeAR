# Demo accounts and demo data

Written 2026-11-24. **No passwords are written here.** All people below are fictional.

## Where the passwords are

`deploy/demo-passwords.txt` (git-ignored, local only; one line per user: username, role, password). It was made by
`python server-django/scripts/demo_data.py` (section 3). `stackadmin` is not in that file: its password is in
`deploy/admin-credentials.txt` (also git-ignored). Seed passwords from the first set-up are in `/data/seed-credentials.txt`
inside the Django container; for the 8 demo users they are **no longer valid** (replaced by the demo script).

new user on the Users page (it is forced) or use Reset password on someone.

## Run it again

```powershell
cd C:\Users\itcell\AndroidStudioProjects\DhruvAR-integration
python server-django\scripts\demo_data.py --check   # list only, changes nothing
python server-django\scripts\demo_data.py           # safe to repeat: existing plans are skipped
```

Needs Python 3.10+, Pillow (`pip install pillow`) and the stack running. It never wipes anything. After a database restore from an older backup,
run it again (it re-sets the demo passwords and re-creates missing plans).
