You are the tech lead for DhruvAR’s geo-map + AR feature.

Read:
- `docs/DhruvAR-Project-Proposal.md`
- `docs/prompts/README.md`
- `docs/prompts/00-SHARED-CONTEXT.md`
- All phase prompts `01`–`06`

Tasks:
1. Inspect the repo and determine which phases are already done vs missing.
2. Produce a short status board: Phase → DONE / PARTIAL / NOT STARTED, with evidence (files).
3. Recommend the **single next phase prompt** to run.
4. List risks if phases are skipped or done out of order.
5. Do **not** implement code unless I explicitly say “implement phase N”.

Output format:
- Status table
- Next action (exact prompt filename)
- Blockers
- Estimated complexity (S/M/L) for the next phase
